# cyoa-core

Framework-agnostic story engine for choose-your-own-adventure web stories. Pure state machine operating on a plain JSON story schema — no rendering, no React dependency.

## Status

Early scaffolding. Schema types are in place; the `StoryEngine`/`useStory`-equivalent state machine and validation utilities are not yet implemented.

## Install

```sh
pnpm add cyoa-core
```
